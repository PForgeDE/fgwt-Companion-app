# Tastenkürzel

[← Dokumentation](README.md)

Das sind die Standardtasten. Unter **Einstellungen → Tastenkürzel** kannst du jede ändern: auf eine Taste klicken und eine neue Kombination drücken; <kbd>Rücktaste</kbd> entfernt sie. Die App markiert dort Tasten, die schon belegt sind, doppelt vorkommen oder auf vielen Tastaturen AltGr-Zeichen sind.

Die Hotkeys wirken auch, während Star Citizen Tasten für sich zurückhält.

| Taste | Wirkung |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>E</kbd> | Regionseditor öffnen |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>O</kbd> | Overlay zeigen / verbergen |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>L</kbd> | Overlay entsperren / sperren |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>B</kbd> | Regionsrahmen auf dem Bildschirm zeigen |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>F1</kbd> … <kbd>F9</kbd> | Modus 1 bis 9 wählen (in Listenreihenfolge) |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>F10</kbd> | Automatischen Moduswechsel an / aus |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>F1</kbd> … <kbd>F9</kbd> | Layout 1 bis 9 wählen |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>N</kbd> | Nächsten Schritt der Checkliste abhaken |
| *(keine)* | Anti-AFK starten oder anhalten – vergibst du selbst |

Im Bildschirm-Editor des Overlay-Designers schließt <kbd>Esc</kbd> den Editor.

**Ein Tastenkürzel tut nichts?** Vielleicht nutzt ein anderes Programm es schon. Unter **Einstellungen → Tastenkürzel** eine andere Kombination wählen.
